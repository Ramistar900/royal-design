## بوابة الاعتماد

1. مقارنة كل مرجع بالرمز الأصلي من ROYAL.
2. الحفاظ على معنى الرمز وسهولة التعرف عليه عند أحجام 128 و256 و512 و1024 بكسل.
3. فصل الأصول CC0 عن الأصول ذات التراخيص المقيدة.
4. عدم تعديل V2–V9 أو استبدال أي رمز في التطبيقات قبل موافقة المستخدم.
5. لا يُعتمد أي أصل خارجي نهائيًا إلا بعد مراجعة المعاينة والترخيص والصيغة المناسبة.
