# ROYAL DESIGN V10 — Icon Study

هذه لوحة اختبار بصرية أولية لاتجاه التصميم الجديد، وليست بديلًا عن مكتبة V2–V9 ولا ملفات إنتاج جاهزة للتطبيقات.

## المعاينة

[فتح لوحة ROYAL V10 (SVG)](royal-v10-icon-study.svg)

## نطاق العينة

- 6 رموز: الرئيسية، حساب المستخدم، الإعدادات، البحث، القهوة، عربة التسوق.
- عائلتان منفصلتان: FLAT وROYAL GLASS.
- داخل كل عائلة: 2D و3D، وكل منهما ثابت ومتحرك.
- الإجمالي: 48 معالجة مرئية ضمن لوحة واحدة.
- الحركات في هذه الدراسة تجريبية وهادئة؛ يلزم اختبارها على الأجهزة قبل اعتمادها.

## بوابة الاعتماد

لا تُستبدل أيقونات V2–V9 ولا تُربط هذه الدراسة بالتطبيقات قبل مراجعة الشكل واعتماد العينة. بعد الاعتماد تُحوّل الرموز إلى ملفات SVG مستقلة، ثم موارد Android ثابتة ومتحركة مناسبة، مع فحوصات المقاسات والوضوح والأداء.
