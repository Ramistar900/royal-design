# معيار رموز ألوان أيقونات ROYAL DESIGN

كل بطاقة أيقونة لها رمز ثابت من **6 خانات** بالشكل `R12345`:
- الحرف الأول يحدد اللون الأساسي للأيقونة.
- الخانات الخمس التالية أرقام فريدة داخل الفهرس.
- الرمز مشتق بصورة حتمية من مفتاح الأيقونة الثابت؛ لذلك يبقى نفسه عند إعادة نشر المعرض ما دامت هوية الأصل ولونه الأساسي ثابتين.
- نسخ 2D والحركة والتركيز وAndroid XML التابعة للمفهوم نفسه تشترك في رمز المفهوم الواحد داخل كتالوج V16/V17. أما الملفات المصدرية المفهرسة منفردة فلها سجل ورمز مستقل.

## بادئات الألوان

| الحرف | اللون |
|---|---|
| R | ذهبي |
| O | برتقالي |
| D | أحمر |
| Y | أصفر |
| G | أخضر |
| T | فيروزي |
| C | سماوي |
| B | أزرق |
| P | بنفسجي |
| H | وردي |
| W | أبيض |
| S | فضي / رمادي |
| K | أسود |
| X | متعدد الألوان أو تعذر تحديد لون واحد |

## كيفية طلب أيقونة

ابحث في [معرض ROYAL DESIGN](https://ramistar900.github.io/royal-design/) برمز الأيقونة، أو افتح ملف [الفهرس JSON](https://ramistar900.github.io/royal-design/icon-codes.json) أو [ملف CSV](https://ramistar900.github.io/royal-design/icon-codes.csv). يمكنك إرسال الرمز وحده مثل `R12345` لتحديد الأيقونة دون لبس.

لون الرمز يصف اللون الأساسي المرئي/المميز في الرسم، ولا يصف لون خلفية الصفحة. قد تظهر الأيقونات متعددة الألوان أو الملفات التي لا يمكن تحليل لونها تلقائيًا ببادئة X.
