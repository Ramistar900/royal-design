# ROYAL Design v8 — Colorful Media & Product Badges

A companion collection for modern Android media players and product-card labels.

- 23 new icon assets, each provided as SVG and Android VectorDrawable XML.
- 24 × 24 viewport; Android vectors use 24dp dimensions.
- Filled multi-color forms using royal blue, emerald, gold, coral, violet, and navy.
- All resources use matching `royal_` names in both formats.
- Added only to this shared design library; no application has been linked or modified.

## Product-card badges

- `royal_badge_new`
- `royal_badge_special_offer`
- `royal_badge_sale`
- `royal_badge_premium`
- `royal_badge_discount`
- `royal_badge_limited`
- `royal_badge_bestseller`
- `royal_badge_trending`
- `royal_badge_featured`
- `royal_badge_gift`

Badge assets provide colorful visual marks. The localized words (NEW, عرض خاص، تنزيلات، PREMIUM, etc.) should be rendered as text overlays by the app UI so Arabic/English wording, font, size, and accessibility remain configurable. The icon library itself stays language-neutral.

## Folders

- SVG: `svg/`
- Android VectorDrawable: `android/res/drawable/`

The Android resources are included in the isolated icon-validation module.
