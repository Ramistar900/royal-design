# ROYAL DESIGN V13 — Original 2D

First independently authored batch: **8 concepts × 2 separate visual styles = 16 SVG assets**.

## Styles
- **Flat:** solid, high-contrast shapes with a restrained ROYAL emerald/gold palette.
- **Glass:** separate translucent panel treatment, layered gradients, bright edge highlights, and a glass-like surface.

## Concepts
- `account` — حساب المستخدم: رأس وكتفان داخل إطار متوازن، مع مساحة سالبة واضحة.
- `home` — الرئيسية: سقف هندسي واضح وواجهة منزل بباب مركزي ونافذتين.
- `search` — بحث: عدسة دائرية بمقبض مستقل ولمعة داخلية صغيرة.
- `settings` — الإعدادات: ترس ثماني الأسنان حول مركز دائري، بتوازن بصري واضح.
- `coffee` — قهوة: فنجان عريض بمقبض جانبي وبخار من ثلاث انحناءات.
- `shopping_bag` — حقيبة التسوق: جسم حقيبة ثابت ومقبض مقوس مع علامة نجمة صغيرة.
- `delivery` — التوصيل: صندوق شحن ومقصورة سائق وعجلتان منفصلتان.
- `wifi` — واي فاي: ثلاث موجات متدرجة ونقطة اتصال مركزية.

## Intellectual-property and provenance
- All 16 SVG files in this batch were authored specifically for ROYAL DESIGN from geometric primitives and original path composition.
- No IconScout file, preview, path, or distinctive marketplace composition was copied, traced, recolored, or modified.
