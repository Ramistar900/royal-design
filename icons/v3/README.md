# ROYAL Android Icons v3 — Preview

This is an additive preview pack for ROYAL Design. **v2 remains unchanged.**

## Formats
- Android VectorDrawable XML: `android/res/drawable/`
- SVG: `svg/`
- Default viewport: 24 × 24
- Default color: currentColor in SVG and a neutral near-black in Android XML; recolor Android vectors with `android:tint` or a theme tint.

## Icon set
- **Wi-Fi** — `royal_wifi`
- **Security Shield** — `royal_security`
- **Smart TV** — `royal_smart_tv`
- **Cast** — `royal_cast`
- **Cloud Sync** — `royal_cloud_sync`
- **Dashboard** — `royal_dashboard`
- **Developer Mode** — `royal_developer_mode`
- **Coffee** — `royal_coffee`
- **Payments** — `royal_payments`
- **Apps Grid** — `royal_apps_grid`

## Usage notes
- SVGs are editable source assets for design tools.
- XML files are Android VectorDrawable resources; copy them into the app's `res/drawable` directory and reference them by resource name.
- Review at 24 dp and larger sizes before using in production. This is a preview pack, not a published release.

## Versioning
v3 is being prepared on branch `royal-android-icons-v3` for review. No application repositories are changed and nothing is published as a release.
