# ROYAL Design V12 — ROYAL+

مجموعة مستقلة لتطبيق **ROYAL+ Launcher**.

- **التصنيف:** إصدار خاص بالتطبيق، وليس مجرد دفعة عامة.
- **الأنماط:** لكل مفهوم ملفان متجاوران: 2D و3D، وكلاهما SVG قابل للتكبير.
- **عدد المفاهيم:** 8.
- **الأصول:** `2d/*.svg` و`3d/*.svg`.
- **الفهرس:** [catalog.json](./catalog.json).
- **المعرض الموحد:** [ROYAL Design](../../../preview/royal-design/index.html).

## الحقوق والمنشأ
جميع الأشكال مؤلفة هندسياً خصيصاً لمكتبة ROYAL Design. لم تُنسخ ملفات من IconScout أو مكتبات أيقونات تجارية، ولم تُتبع أو تُلوّن رسومات طرف ثالث. الترخيص الداخلي: `ROYAL_ORIGINAL`.
