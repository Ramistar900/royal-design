# ROYAL Café & Orders — v9

This collection is being expanded for café and restaurant products, order states, delivery, booking, and payment.

## Current static icons
- `royal_coffee` — coffee cup
- `royal_juice` — juice drink

## Motion companions
Static icons remain unchanged. Motion assets are optional companions and live in separate paths:
- Animated SVG: `motion/svg/`
- Android AnimatedVectorDrawable resources: `android/res/drawable/*_animated.xml`
- Android motion base vectors: `android/res/drawable/*_motion_base.xml`
- Android animators: `android/res/animator/`

Current motion:
- Coffee: gentle rising steam.
- Juice: softly floating bubbles and a subtle sparkle.

Use the animated Android resources where animated-vector playback is supported; retain the matching static drawable as the reduced-motion/fallback option. SVG motion uses SMIL animations. Keep motion brief, calm, and non-distracting.

## Palette
Coffee brown `#8B5A3C`, juice coral `#F26D5B`, warm cream `#F5D7A1` / `#FFE5A8`, and white.
