# ROYAL Design v6 — Colorful Finance & Shopping

A new colorful companion collection for the ROYAL icon library. It complements the clean outline icons in v5 with bright, filled multi-color artwork.

- 12 original icons in SVG and Android VectorDrawable formats.
- Palette: royal blue, emerald, warm gold, coral, and violet.
- Style: compact 24 × 24 filled shapes with clear color separation.
- SVG and Android XML files share matching `royal_` resource names.
- This is a library-only addition; no application repositories are changed.

## Icon set

- `royal_gift_box`
- `royal_delivery_truck`
- `royal_store`
- `royal_package`
- `royal_coupon`
- `royal_barcode`
- `royal_qr_payment`
- `royal_loyalty_star`
- `royal_safe`
- `royal_bank`
- `royal_return`
- `royal_wishlist`

## Folders

- SVG sources: `svg/`
- Android VectorDrawable resources: `android/res/drawable/`

Android XML resources are included in the isolated icon-validation module. Review the artwork at actual UI sizes before production use.
