# ROYAL Design v7 — Colorful Controls & Media

A modern, colorful icon collection for Android navigation, settings, window actions, and music controls.

- 26 original icons in matching SVG and Android VectorDrawable formats.
- Canvas: 24 × 24; Android resources: 24dp.
- Filled, layered multi-color shapes with a restrained royal palette.
- Palette: royal blue, emerald, gold, coral, and violet.
- Resource names use the `royal_` prefix and match across both formats.
- Library-only addition: no application repository is modified or linked.
