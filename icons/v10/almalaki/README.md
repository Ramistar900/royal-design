# ROYAL Design V10 — الملكي / ALMALAKI

**48 مفهوماً أصلياً، 96 ملفاً ثابتاً (2D + 3D)، و48 نسخة حركة منفصلة.**

## لوحة الألوان الملكية
- أزرق ملكي مشبع: `#236BFF`
- أرجواني غني: `#8B35E8`
- ذهبي معدني لامع: `#FFF5C7 / #F8D56C / #C88B18`
- أسود عميق: `#080B18`
- أبيض نقي: `#FFFFFF`

اللمعان والانعكاس جزء من الرسم الثابت ولا يتحركان. الحركة محفوظة في مجلد مستقل.

## التغطية
المطعم والمقهى، القائمة، المنتجات والتصنيفات والإضافات، العملاء والمالك والموظفون والفروع، المطبخ والطاهي، السلة والطلبات والحجوزات والطاولات، QR والتناول داخل المطعم والسفري، التوصيل والسائق والاستلام والعناوين، الدفع والفواتير والإيصالات والنقد والمحفظة والبطاقات والاسترداد والخصومات والقسائم والولاء، التقييمات والإشعارات، المبيعات والتحليلات والمخزون والتنبيهات والطباعة والدعم والإعدادات واللغة.

## قواعد الحركة
بخار القهوة متموّج، الترس يدور ويتوقف لحظة ثم يستأنف، العربة تتحرك عند الإضافة، المركبة تتقدم وتتوقف، الطابعة تُخرج الإيصال، والرسوم البيانية ترتفع. شغّل الحركة عند ظهور الأيقونة أو تنفيذ الوظيفة فقط، وأوقفها خارج الشاشة. عند تفعيل تقليل الحركة تُستخدم النسخة الثابتة المقابلة. لا توجد حركة تلقائية في الخلفية.

## المنشأ والتوافق
الأشكال مرسومة هندسياً خصيصاً لـROYAL Design، دون نسخ أو تتبع ملفات تجارية. كل SVG يحمل بيانات المنشأ والترخيص الداخلي `ROYAL_ORIGINAL`. هذا توثيق للمصدر وليس ضماناً قانونياً مطلقاً. ملفات SVG هي مصادر التصميم؛ يلزم تصدير Android VectorDrawable/AnimatedVectorDrawable وفحص عرض Android 8 والتلفاز قبل إدخالها إلى التطبيقات. الحالة الحالية: قيد المراجعة البصرية والاختبار.
