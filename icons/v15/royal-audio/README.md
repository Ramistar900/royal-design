# ROYAL Design V15 — ROYAL AUDIO

مجموعة أيقونات أصلية لمشغل ROYAL AUDIO والمشاهد الطبيعية والمؤثرات الصوتية.

- **عدد المفاهيم:** 12.
- **الأنماط:** 2D و3D، وكل نمط ملف SVG مستقل.
- **المحتوى:** مشغل الصوت، المطر، الرعد، الرياح، العصافير، البومة، ماء البحيرة، النار، أمواج البحر، كتم الصوت والتنزيل والتشغيل.
- **قيود المحتوى:** أيقونات هذه المجموعة لا تمثل أصواتاً بشرية أو موسيقى خلفية، وتبقى المكتبة ملتزمة بسياسة المؤثرات غير اللفظية.
- **المعرض:** [ROYAL Design](../../../preview/royal-design/index.html).
- **الفهرس:** [catalog.json](./catalog.json).

## الحقوق والمنشأ
كل أصل مرسوم هندسياً خصيصاً لـROYAL AUDIO وROYAL Design. لا ملفات أو مسارات أو تراكيب منقولة من مكتبات تجارية. الترخيص الداخلي `ROYAL_ORIGINAL`.
