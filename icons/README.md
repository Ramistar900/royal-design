# فهرس مكتبة ROYAL Design

تضم المكتبة مجموعتين واضحتين:

1. **المكتبة التاريخية المشتركة V2–V9**: الأيقونات القديمة وموارد Android والحركة، محفوظة دون تغيير.
2. **مجموعات خاصة بالتطبيقات V10–V15**: لكل تطبيق إصدار مستقل، ولكل مفهوم أيقونة نسخة 2D ونسخة 3D بالاسم والمفتاح نفسيهما.

## الحقوق

جميع ملفات V10–V14 الجديدة منشأة خصيصاً لـROYAL Design باستخدام مسارات هندسية أصلية وتدرجات وظلال من تصميمنا. لم تُنسخ أو تُتبع أي رسومات من IconScout أو أي مكتبة تجارية، ولا تستخدم شعارات شركات أخرى. كل عنصر يحمل بيانات منشأ `original_royal` وترخيص داخلي `ROYAL_ORIGINAL`.
