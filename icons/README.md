# فهرس مكتبة ROYAL Design للأيقونات

هذا هو الفهرس المرجعي الموحد لكل الأيقونات في المستودع، من **V2 حتى V9**. يتضمن الأسماء العربية، مفاتيح الاستخدام، معرّفات Android، ومسارات ملفات SVG وVectorDrawable وملفات الحركة المتاحة.

## الوصول السريع

- [المعاينة المرئية التفاعلية والبحث ونسخ المعرّفات](../preview/v9-icon-catalog/index.html)
- [الفهرس الآلي بصيغة JSON](./catalog.json)
- [الصفحة الرئيسية للمستودع](../README.md)

> ملاحظة V2: ملفات SVG متاحة منفردة، بينما ملفات Android الأصلية موجودة داخل أرشيف V2. وفي V4، اسم SVG يختلف عن اسم مورد Android؛ لذلك يعرض الفهرس الاثنين بشكل منفصل.

1. انسخ اسم مورد Android من عمود **Android Resource**، ولا تفترض أن اسم ملف SVG هو نفسه.
2. موارد Android في V2 تُستخرج من [أرشيف V2](../ROYAL_Android_Icons_v2.zip).
3. الحركة في V9 اختيارية؛ استخدم المورد الثابت كبديل واحترم إعدادات تقليل الحركة.
4. أسماء الملفات محايدة لغوياً؛ الأسماء العربية هنا للتعريف فقط.
5. الفهرسة لا تعني دمج الأيقونات تلقائياً في Almalaki أو ROYAL TV أو ROYAL+.
