# ROYAL Design

المكتبة الحالية لأصول ROYAL المعتمدة.

## الإصدارات الحالية

- **V16 وV17:** ملفات المصدر الكاملة والكتالوجات الأصلية من مستودع [royal-design-gallery](https://github.com/Ramistar900/royal-design-gallery).
- **V18:** مكتبة الأيقونات الحالية للتلفاز والمتجر والمشغلات، مع 451 ملف SVG.
- **ROYAL AUDIO:** مكتبة الصوتيات محفوظة ومستقلة عن الأيقونات.

## المعرض

افتح [معرض ROYAL DESIGN](https://ramistar900.github.io/royal-design/) لعرض الأصول الحالية وملفات المصدر والأرشيفات.

## رموز الأيقونات

لكل بطاقة أيقونة رمز ثابت من ست خانات: حرف واحد يحدد اللون الأساسي وخمس خانات رقمية، مثل `R12345` للذهبي. المعرض المنشور يوفر [فهرس JSON](https://ramistar900.github.io/royal-design/icon-codes.json) و[فهرس CSV](https://ramistar900.github.io/royal-design/icon-codes.csv) قابلين للبحث والاستخدام البرمجي، ويعرض زر نسخ الرمز على كل بطاقة.
