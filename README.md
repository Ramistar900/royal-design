# ROYAL Design

Private shared design and icon library for ROYAL projects.

## المعرض والفهرس

- **[افتح معرض ROYAL Design التفاعلي](./preview/royal-design/index.html)** — اختر التطبيق والإصدار، وابحث بالعربية أو بالاسم البرمجي، واعرض نسختي 2D و3D جنباً إلى جنب.
- **[فهرس مجموعات التطبيقات](./icons/app-collections.json)** — الفهرس الآلي الموحد، مع أسماء الأيقونات ومسارات الملفات وحالة كل نسخة وبيانات المنشأ.
- **[الفهرس التفصيلي ومعاينات الصور](./gallery/README.md)** — صور وروابط 2D و3D لكل تطبيق.
- **[فهرس المكتبة القديمة V2–V9](./icons/README.md)** — الأصول السابقة ومفاتيحها وموارد Android.

## حقوق الملكية والمنشأ

الأصول الجديدة مؤلفة هندسياً خصيصاً لمكتبة ROYAL Design، تحت سجل `ROYAL_ORIGINAL`. لا تتضمن ملفات IconScout أو مكتبات أيقونات تجارية، ولا شعارات علامات تجارية أو رسومات منسوخة أو متتبعة. هذا سجل منشأ للأعمال الأصلية؛ ويجب إجراء مراجعة بشرية قبل أي توزيع تجاري خارجي.

## أصول المكتبة السابقة

مكتبة V2–V9 القديمة محفوظة كما هي، بإجمالي 162 مفهوماً مع موارد Android، إضافة إلى مجموعة V10 المصدرية القديمة ودفعة V13 العامة السابقة. لم تُحذف أو تُستبدل هذه الملفات عند إنشاء مجموعات التطبيقات الجديدة.
