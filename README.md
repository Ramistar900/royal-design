# ROYAL Design

Private shared design and icon library for ROYAL projects.

## Android Icons v2

The version 2 archive contains Android VectorDrawable XML and SVG icon assets.

- Archive: [ROYAL_Android_Icons_v2.zip](./ROYAL_Android_Icons_v2.zip)
