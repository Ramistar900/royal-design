# Audio provenance and licensing

Keep one record per audio pack or track here. A track must not enter the public catalog until its audio file and redistribution/embedding rights are verified.

Required fields in each record:
- Track ID and filename
- Creator/performer and source
- License name and license URL or evidence reference
- Whether commercial use and redistribution are permitted
- Attribution text, if required
- Whether edits/normalization/format conversion were made
- Date checked

Do not treat a publicly playable or downloadable file as automatically licensed for redistribution.
