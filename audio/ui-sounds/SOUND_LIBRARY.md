# مكتبة أصوات الأزرار والاختيارات

تحتوي المكتبة على 49 صوتاً مرتبطاً بوظيفة كل زر أو اختيار. الملفات بصيغة WAV ومعدل 44.1 kHz.

## الأصوات حسب التصنيف

- **`sounds/nav/focus_move.wav`**: نقرة ناعمة قصيرة. الاستخدام: تنقل بين عناصر القائمة أو الأزرار.
- **`sounds/nav/select.wav`**: نقرة مزدوجة واضحة. الاستخدام: اختيار عنصر أو فتح صفحة.
- **`sounds/nav/back.wav`**: نغمة هابطة قصيرة. الاستخدام: زر الرجوع.
- **`sounds/nav/open_menu.wav`**: صعود ناعم. الاستخدام: فتح قائمة أو لوحة.
- **`sounds/nav/close_menu.wav`**: هبوط ناعم. الاستخدام: إغلاق قائمة أو لوحة.
- **`sounds/nav/home.wav`**: نغمتان صاعدتان. الاستخدام: الوصول إلى الصفحة الرئيسية.
- **`sounds/nav/tv_focus.wav`**: لمعة زجاجية خفيفة. الاستخدام: تحريك التركيز بريموت التلفاز.
- **`sounds/nav/scroll_tick.wav`**: نقرة دقيقة جداً. الاستخدام: التمرير في القوائم الطويلة.
- **`sounds/nav/swipe.wav`**: انزلاق هوائي. الاستخدام: السحب أو التبديل بين الشرائح.
- **`sounds/nav/error.wav`**: زمزمة رفض. الاستخدام: عنصر غير متاح أو إجراء مرفوض.
- **`sounds/select/toggle_on.wav`**: صوت تفعيل صاعد. الاستخدام: تشغيل مفتاح أو خيار.
- **`sounds/select/toggle_off.wav`**: صوت إيقاف هابط. الاستخدام: إيقاف مفتاح أو خيار.
- **`sounds/select/check.wav`**: نقرة مربع الاختيار. الاستخدام: تحديد خانة اختيار.
- **`sounds/select/radio.wav`**: نقرة اختيار واحد. الاستخدام: اختيار خيار من قائمة إختيارات.
- **`sounds/select/search_start.wav`**: نغمتان قصيرتان. الاستخدام: بدء البحث أو فتح حقل الإدخال.
- **`sounds/action/confirm.wav`**: ثلاثية موسيقية هادئة. الاستخدام: تأكيد إجراء أو حفظ.
- **`sounds/action/success.wav`**: تصاعد مشرق. الاستخدام: نجاح عملية أو اكتمال دفع أو تسجيل دخول.
- **`sounds/action/error.wav`**: نبضتان منخفضتان. الاستخدام: خطأ في عملية.
- **`sounds/action/warning.wav`**: نبضتان متوسطتان. الاستخدام: تنبيه قبل إجراء حساس.
- **`sounds/action/add_to_cart.wav`**: نقرتان لامعتان ولمعة. الاستخدام: إضافة منتج إلى السلة.
- **`sounds/action/add.wav`**: صعود قصير. الاستخدام: إضافة عنصر إلى قائمة أو مفضلة.
- **`sounds/action/remove.wav`**: نبضة هابطة ناعمة. الاستخدام: حذف عنصر من السلة أو القائمة.
- **`sounds/action/delete.wav`**: هسهسة وطرقة خفيفة. الاستخدام: حذف نهائي.
- **`sounds/action/favorite.wav`**: لمعات متتالية. الاستخدام: إضافة إلى المفضلة أو تقييم.
- **`sounds/action/share.wav`**: هسهسة صاعدة. الاستخدام: مشاركة المحتوى.
- **`sounds/action/download.wav`**: ثلاث نقرات صاعدة. الاستخدام: بدء التحميل أو اكتماله.
- **`sounds/action/check_done.wav`**: نغمة اكتمال هادئة. الاستخدام: اكتمال مهمة أو حفظ تلقائي.
- **`sounds/action/toggle_warning.wav`**: تنبيه بين نغمتين. الاستخدام: تغيير حالة يحتاج انتباهاً.
- **`sounds/media/play.wav`**: صعود قصير مبهج. الاستخدام: تشغيل المحتوى.
- **`sounds/media/pause.wav`**: هبوط قصير. الاستخدام: إيقاف مؤقت.
- **`sounds/media/stop.wav`**: هبوط حاد وقصير. الاستخدام: إيقاف التشغيل كاملاً.
- **`sounds/media/next.wav`**: هسهسة نحو اليمين. الاستخدام: الانتقال إلى المقطع التالي.
- **`sounds/media/prev.wav`**: هسهسة نحو اليسار. الاستخدام: الرجوع إلى المقطع السابق.
- **`sounds/media/seek.wav`**: نقرات تقديم وترجيع. الاستخدام: التقديم أو الترجيع داخل المقطع.
- **`sounds/media/volume_tick.wav`**: نقرة الصوت. الاستخدام: تغيير مستوى الصوت خطوة بخطوة.
- **`sounds/media/mute.wav`**: طرقة خافتة منخفضة. الاستخدام: كتم الصوت.
- **`sounds/media/unmute.wav`**: صعود لامع. الاستخدام: إلغاء الكتم.
- **`sounds/media/fullscreen_enter.wav`**: تحول صاعد واسع. الاستخدام: الدخول إلى ملء الشاشة.
- **`sounds/media/fullscreen_exit.wav`**: تحول هابط. الاستخدام: الخروج من ملء الشاشة.
- **`sounds/media/record_start.wav`**: نبضتان قصيرتان. الاستخدام: بدء التسجيل أو الكاريوكي.
- **`sounds/media/record_stop.wav`**: نبضة منخفضة واحدة. الاستخدام: إيقاف التسجيل.
- **`sounds/media/subtitle_on.wav`**: نقرة إيجابية. الاستخدام: تشغيل الترجمة.
- **`sounds/tv/channel_change.wav`**: تشويش قصير وصوت مميز. الاستخدام: تغيير القناة.
- **`sounds/tv/power_on.wav`**: تصاعد كوردي. الاستخدام: تشغيل التلفاز.
- **`sounds/tv/power_off.wav`**: تلاشي هابط. الاستخدام: إطفاء التلفاز أو وضع السكون.
- **`sounds/system/notification.wav`**: جرس مزدوج. الاستخدام: إشعار جديد.
- **`sounds/system/loading_tick.wav`**: نقرة دورية خفيفة. الاستخدام: تحميل أو تحديث (تكرار).
- **`sounds/system/lock.wav`**: قفل معدني خفيف. الاستخدام: قفل أو فتح محتوى محمي.
- **`sounds/system/keypad_tap.wav`**: نقرة لوحة مفاتيح. الاستخدام: ضغط أزرار الإدخال الرقمي.

## ملاحظات

- الأصوات مولّدة برمجياً لتكون نظيفة ومتناسقة، ولم تُسجَّل من مصدر حقيقي. يُنصح بالاستماع إليها على الجهاز الفعلي وضبط مستوى الصوت.
- الأسماء ثابتة، لذلك يمكن استبدال أي ملف بتسجيل احترافي بنفس الاسم دون تعديل التطبيق.
- في أندرويد التلفاز استخدم SoundPool للأصوات القصيرة لتفادي التأخير، وحدد مستوى الصوت حسب إعدادات الجهاز.
