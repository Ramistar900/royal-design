# ROYAL UI SOUNDS

مكتبة مستقلة لمؤثرات واجهة المستخدم والتنقل والتحكم والوسائط. تحتوي على 49 مؤثراً قصيراً بصيغة WAV، بمعدل 44.1 kHz، قناة واحدة، و16-bit PCM.

## الفصل عن ROYAL AUDIO

هذه المكتبة مخصصة لأصوات الواجهة فقط، ولا تضاف إلى كتالوج أصوات الطبيعة أو الطقس في `audio/catalog.json`. تبقى مكتبة الطبيعة والطقس مستقلة دون تغيير.

## التصنيفات

- `sounds/nav/`: التنقل والتركيز والرجوع والقوائم
- `sounds/select/`: الاختيارات ومفاتيح التبديل
- `sounds/action/`: التأكيد والنجاح والإضافة والحذف
- `sounds/media/`: تشغيل الوسائط والتحكم بها
- `sounds/tv/`: القنوات وتشغيل/إطفاء التلفاز
- `sounds/system/`: الإشعارات والقفل ولوحة المفاتيح

## المصدر والتحقق

تم استخراج الملفات من `restaurant_tv_sound_library.zip` مع الاحتفاظ بالبيان والتوثيق الأصليين. يصف التوثيق الأصلي الأصوات بأنها مولّدة برمجياً ولا تستخدم عينات صوتية خارجية. يجب إجراء اختبار استماع فعلي قبل اعتمادها داخل أي تطبيق.

**مهم:** هذه إضافة إلى مكتبة التصميم فقط؛ لا يتم تفعيل الأصوات تلقائياً داخل التطبيقات.
