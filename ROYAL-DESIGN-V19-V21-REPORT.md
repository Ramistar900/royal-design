# ROYAL Design V19–V21

## V19 — Muslim
- 22 concepts, each with static and animated SVG variants (44 SVGs).
- Mosque, dua hands, open Quran, reciters in a mosque niche, Hijri calendar with minarets, Ramadan crescent, Hadith Arabic tile, prayer times, Qibla, tasbih, azkar, dhikr, zakat, charity, fasting/iftar, salah, Quran audio/bookmark, Islamic events, wudu and Eid.

## V20 — Sports
- 25 concepts, each with static and animated SVG variants (50 SVGs).
- Today matches, live scores, match results, fixtures, standings, football, basketball, tennis, volleyball, cricket, trophy, teams, players, stadium, goal, whistle, yellow/red cards, medal, statistics, tournament bracket, transfers, sports news, replay and match stopwatch.
- Icons are functional symbols only; they do not contain live match results or data.

## V21 — Weather
- 26 concepts, each with static and animated SVG variants (52 SVGs).
- Sunny, partly cloudy, cloudy, rain, drizzle, heavy rain, thunderstorm, lightning, snow, heavy snow, sleet, hail, wind, strong wind, fog, mist, dust, heat, cold, sunrise, sunset, clear night, tornado, temperature, humidity and rainbow.
- Rain, thunder and wind reuse V15 ROYAL weather artwork geometry from the existing two-dimensional assets and expand it into additional weather conditions.

All icons use a 128×128 viewBox, separate static and animated files, basic SVG gradients, and SMIL animate/animateTransform. No JavaScript, CSS keyframes, filters or external resources are used inside SVG files.

Android 8 motion playback requires a SMIL-capable SVG renderer such as WebView. Native static-image or VectorDrawable-only loaders show the static artwork but do not play SMIL.
