# ROYAL Design — المعرض التفاعلي

افتح `index.html` من هذا المجلد بعد تنزيل ملفات المكتبة كاملة أو من بيئة تستضيف مسارات المستودع النسبية.

- يحمّل الفهرس من `../../icons/app-collections.json`.
- يعرض مجموعات V10–V14 بحسب التطبيق.
- يعرض نسختي 2D و3D جنباً إلى جنب.
- البحث يشمل الاسم العربي والإنجليزي ومفتاح الأيقونة.
- كل صورة تفتح ملف SVG الأصلي مباشرة.

المستودع خاص. لا توجد استضافة عامة مفعلة لهذا المعرض، ولا يتم نشر أصوله خارج المستودع.
