# ROYAL DESIGN — First Visual Review Batch

Status: candidate shortlist only — **not approved and not imported**  
Prepared: 2026-11-08  
Target libraries: V10 (2D), V11 (3D)  
Motion assets are excluded from this review and remain in V12.

## Review rules

- Review the meaning, silhouette, legibility at small sizes, visual balance, and consistency.
- Compare 2D Flat separately from 2D Glass; compare 3D finishes separately.
- For 3Dicons, use only the V1 files covered by the repository's CC0-1.0 license. Do not use the `premium` render URL in this shortlist.
- A candidate is not accepted merely because it appears in this document. Import only after visual review and approval.
- Preserve all existing V2–V9 assets during review.
